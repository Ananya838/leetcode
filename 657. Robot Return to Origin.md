# LeetCode 657 — Robot Return to Origin

## Problem

A robot starts at `(0, 0)`.

It receives moves:

- `U` → Up
- `D` → Down
- `L` → Left
- `R` → Right

Return `True` if the robot comes back to `(0, 0)`.

---

## Logic

Track the robot's position using:

- `x` → left/right
- `y` → up/down

Moves:

```text

```
x == 0 and y == 0
```

```
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        x = 0
        y = 0

        for move in moves:
            if move == 'U':
                y += 1
            elif move == 'D':
                y -= 1
            elif move == 'R':
                x += 1
            elif move == 'L':
                x -= 1

        return x == 0 and y == 0

```


moves = "UDLR"

Start: (0, 0)

U → (0, 1)
D → (0, 0)
L → (-1, 0)
R → (0, 0)

Answer: True


Pattern

This is a simulation / coordinate tracking problem.

Time: O(n)

Space: O(1)




**Key idea to remember:** opposite moves cancel each other: `U-D` and `L-R`.
