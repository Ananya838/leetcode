# LeetCode 994 — Rotting Oranges

## Problem

We are given a grid:

- `0` → Empty cell
- `1` → Fresh orange
- `2` → Rotten orange

Every minute, a rotten orange makes its **4-directionally adjacent** fresh oranges rotten.

Return the minimum number of minutes required to rot all fresh oranges.

If some fresh orange can never become rotten, return `-1`.

---

## Example

```text
2 1 1
1 1 0
0 1 1



###Main logic
```
Multiple starting points
        +
All start at the same time
        +
They spread to neighboring cells
        +
We need minimum time
```


```
from collections import deque

class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:

        rows = len(grid)
        cols = len(grid[0])

        queue = deque()
        minit = 0

        directions = [
            (0, -1),
            (0, 1),
            (-1, 0),
            (1, 0)
        ]

        # Add all initially rotten oranges
        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == 2:
                    queue.append((row, col))

        # Multi-Source BFS
        while queue:

            # Current BFS level
            size = len(queue)

            # Track whether anything became rotten
            rotted = False

            # Process only the current level
            for _ in range(size):

                row, col = queue.popleft()

                # Check four directions
                for dr, dc in directions:

                    nr = row + dr
                    nc = col + dc

                    # Boundary check
                    if nr < 0 or nr >= rows or nc < 0 or nc >= cols:
                        continue

                    # Fresh orange
                    if grid[nr][nc] == 1:

                        # Make it rotten
                        grid[nr][nc] = 2

                        # Add for the next BFS level
                        queue.append((nr, nc))

                        rotted = True

            # One minute passed only if spreading happened
            if rotted:
                minit += 1

        # Check if any fresh orange remains
        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == 1:
                    return -1

        return minit
```




Problem:
Rotting Oranges

Pattern:
Multi-Source BFS

Why BFS?
Because spreading happens level by level.

Why Multi-Source?
Because multiple rotten oranges start simultaneously.

Initial step:
Put every rotten orange into the queue.

Important:
size = len(queue)

Meaning:
Process only the current BFS level.

Time:
One BFS level = One minute.

Fresh orange:
1 → 2

Visited:
Grid itself can act as visited.

Directions:
Up, Down, Left, Right.

Time increment:
Only if at least one fresh orange became rotten.

End:
If any 1 remains → -1.

Complexity:
O(R × C) time
O(R × C) space
```

```
##Complete Algorithm

1. BFS is useful for minimum steps/time.

2. Multiple simultaneous sources
   → Multi-Source BFS.

3. Put all sources into the queue initially.

4. One BFS level can represent one unit of time.

5. size = len(queue)
   separates the current level from the next level.

6. Newly discovered nodes belong to the next level.

7. The grid can sometimes act as visited.

8. Check all four directions.

9. Always check boundaries.

10. Count time per level, not per node.

11. Check for unreachable cells at the end.
```
