# Restore IP Addresses — Backtracking

## Core Idea

An IP address has exactly **4 parts**.

For every position, try taking:

```text
1 digit
2 digits
3 digits
```

Example:

```text
25525511135
↑
index = 0

"2"    → possible
"25"   → possible
"255"  → possible
```

---

## ⭐ Important: `index`, `end` and slicing

This is the most important part.

```python
for end in range(index + 1, min(index + 4, len(s) + 1)):
    part = s[index:end]
```

### What is `index`?

`index` = **where the next IP part starts**.

Example:

```text
255|25511135
   ↑
 index = 3
```

### What is `end`?

`end` = **position after the characters we currently want to take**.

Python slicing:

```python
s[index:end]
```

does NOT include `end`.

If:

```text
index = 0
```

then:

```text
end = 1 → s[0:1] → "2"
end = 2 → s[0:2] → "25"
end = 3 → s[0:3] → "255"
```

Therefore:

```text
1 digit → index + 1
2 digits → index + 2
3 digits → index + 3
```

Because `range()` excludes its ending value:

```python
range(index + 1, index + 4)
```

produces:

```text
index+1, index+2, index+3
```

`min()` makes sure we don't go beyond the string:

```python
min(index + 4, len(s) + 1)
```

### Why `backtrack(end)`?

If we choose:

```text
255
```

then:

```text
255|25511135
   ↑
   3
```

So:

```python
backtrack(end, path)
```

means:

> "I consumed characters up to `end`; start the next part from `end`."

---

## State

```text
index → where we are in the string
path  → IP parts chosen so far
```

## Choice

```text
Take 1 digit
Take 2 digits
Take 3 digits
```

## Constraints / Pruning

```python
if len(part) > 1 and part[0] == '0':
    continue
```

Reject leading zeros:

```text
0   ✅
01  ❌
001 ❌
```

```python
if int(part) > 255:
    continue
```

Reject values greater than `255`.

---

## Stop / Success

```python
if len(path) == 4:
    if index == len(s):
        result.append(".".join(path))
    return
```

Success requires:

```text
4 parts + entire string consumed
```

---

## Undo

```python
path.append(part)
backtrack(end, path)
path.pop()
```

```text
Choose → Explore → Undo
```

---

## Code

```python
class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:

        result = []
        path = []

        def backtrack(index, path):

            if len(path) == 4:
                if index == len(s):
                    result.append(".".join(path))
                return

            for end in range(index + 1, min(index + 4, len(s) + 1)):

                part = s[index:end]

                if len(part) > 1 and part[0] == '0':
                    continue

                if int(part) > 255:
                    continue

                path.append(part)
                backtrack(end, path)
                path.pop()

        backtrack(0, [])
        return result
```

### 🔑 One-line memory trick

```text
index = where to start
end   = where to stop
s[index:end] = current part
backtrack(end) = start after current part
```
